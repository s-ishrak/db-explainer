Every line has a different order. Some names are short or crossed out.

Why the table is better

  • Every row looks the same.
  • Same order in every row.
  • Easy to find any phone number.

Organized table

Let’s put the same information into a table.

A database is an organized collection of data. It keeps data in tables, so a computer can store, find and change it easily.

Step 3 · Primary key

Who is who?

Two students have the same name. How do we know which one is which?

Head teacher“Please send Rahim Uddin to my office.”
Try both buttons. Which one finds only one student?

PRIMARY KEY A field that is different for every record. Here, it is Roll.

No two students share a roll, and it is never empty.

Names can repeat. Brothers and sisters may share a phone. So Name and Phone are not good keys.

Teacher’s note: In many schools, rolls repeat across classes, so a unique Student ID is the real key.

Step 5 · Searching and sorting

Find and order data fast

Type in the search box to find a student. Click a column heading to sort.

This is what a database does for us. It can search and sort thousands of records in less than a second. In a notebook, this would take a very long time.
